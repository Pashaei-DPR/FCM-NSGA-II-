# Unsupervised Plank Posture Assessment

Fuzzy C-Means clustering and multi-objective (NSGA-II) threshold optimization for label-free evaluation of plank posture.

Code and data accompanying the paper **"Unsupervised Plank Posture Assessment Using Fuzzy C-Means Clustering and Multi-Objective Threshold Optimization"** (Pashaei, Mortezania, Amiri; Department of Engineering Sciences, University of Tehran).

---

## Overview

Supervised posture classifiers need large, expert-labelled datasets, and fixed-angle rules (e.g. exactly 90°/180°) break down under natural anatomical variation and noisy 2D pose estimation. This project evaluates plank posture **without a labelled training set**:

1. **Pose extraction**: MediaPipe Pose gives 2D landmarks (wrist, elbow, shoulder, hip, knee, ankle).
2. **Feature engineering**: four joint angles (elbow, shoulder, hip, knee), standardized with `StandardScaler`.
3. **Fuzzy C-Means**: the cluster count `C` and fuzzifier `m` are tuned by grid search on the Fuzzy Partition Coefficient (selected: `C = 4`, `m = 1.5`, FPC = 0.890).
4. **Target-cluster identification**: the cluster whose centroid is closest (Euclidean) to the ideal plank template **90° / 90° / 180° / 180°** is the "correct form" cluster.
5. **NSGA-II threshold optimization**: finds the membership cut-off (50–99.9 %) that trades off *angle error* (MSE to the ideal template) against *retention cost* (fraction of samples dropped). The final threshold is the Pareto solution closest to the utopia point. Samples in the target cluster below the cut-off are moved to a "borderline / discarded" cluster for expert review.
6. **Error diagnosis**: the remaining clusters are compared with the ideal template to report joint-specific deviations (top two per posture).
7. **Validation**: predictions are compared with expert annotations on an independent test set of 69 images.

## Key results

Test set: 69 held-out real images, annotated by two raters with adjudication by a coach. All stochastic methods were run over 5 seeds (mean ± SD).

| Method | Retained / 69 | Accuracy | F1 | Cohen's κ |
|---|---|---|---|---|
| Rule-based (±14°) | 69.0 | 0.507 | 0.227 | 0.113 |
| K-Means | 69.0 | 0.797 | 0.844 | 0.567 |
| FCM | 69.0 | 0.812 | 0.854 | 0.600 |
| FCM + grid search | 63.0 | 0.857 | 0.889 | 0.693 |
| DBSCAN (NSGA-II tuned) | 53.4 | 0.936 | 0.955 | 0.848 |
| **FCM + NSGA-II** | **58.2 ± 4.4** | **0.899** | **0.921** | **0.783** |

- FCM + NSGA-II had the lowest cumulative error among the FCM variants (22.17 ± 0.65°).
- It clearly outperformed the fixed-tolerance rule and DBSCAN at matched retention.
- **Important caveat:** on the images retained by *all* methods (~50 of 69), the main clustering methods perform identically (κ = 0.887, F1 = 0.966). The benefit of FCM + NSGA-II comes from **withholding ambiguous samples for expert review**, not from better clustering of easy cases. It is best used as an expert-in-the-loop decision-support tool.

See the paper for the full tables, confidence intervals, and per-seed results.

> `code.ipynb` reads `test.csv` and `expert_labeling.csv`. `expert_labeling.csv` is generated by `agreement.ipynb`. 

### Data format

| File | Columns |
|---|---|
| `plank_classification.csv`, `test.csv` | `filename`, `head_side` (`LEFT`/`RIGHT`), `ELBOW_ANGLE`, `SHOULDER_ANGLE`, `HIP_ANGLE`, `KNEE_ANGLE` |
| `expert_1.csv`, `expert_2.csv` | `filename`, `head_side`, `ELBOW_ANG`, `SHOULDER_ANG`, `HIP_ANG`, `KNEE_ANG` (1 = joint error, blank/0 = no error) |
| `expert_labeling.csv` | merged labels plus a `needs_review` flag |

The training images come from the public Roboflow **Plank** dataset ([Liu, 2024](https://universe.roboflow.com/xiaoyu-liu/planku75si)): 617 images, of which 316 remained after manual screening (unsuitable camera angle, graphical images) and automatic exclusion (no MediaPipe detection). The 69 test images are real photos collected from various online sources. Images themselves are not redistributed here.

## Usage

### 1. Inter-rater agreement and label merging

Run `agreement.ipynb` (first cell). It:

- aligns `expert_1.csv` and `expert_2.csv` by filename,
- computes percent agreement, Cohen's κ (with 2000-resample percentile bootstrap CIs), and positive/negative specific agreement per joint,
- writes `inter_rater_agreement.csv` and `expert_labeling.csv`.

`DISAGREE_RULE` controls how disagreements are merged: `"either"` (flag an error if either rater did) or `"flag"` (leave undecided). Disagreements are referred to an adjudicator, and the final reference labels should reflect that adjudication.

### 2. Main pipeline

Open and run `code.ipynb` top to bottom. Main sections:

| Section | Content |
|---|---|
| 2 | Data loading, constants (`TARGET_ANGLES = [90, 90, 180, 180]`, seeds `42, 123, 1234, 12345, 123456`) |
| 3–7 | K-Means, DBSCAN (NSGA-II tuned), Hierarchical, GMM, FCM on the training set |
| 8–10 | FCM membership-threshold optimization with NSGA-II, Pareto fronts, grid-search and hypervolume comparison |
| 11 | Retention-matched DBSCAN and rule-based baseline |
| 12–15 | Save training results, assign test samples, identify the correct cluster, per-cluster error analysis |
| 16–17 | Evaluation against expert labels (own-retained and common subsets) |
| 18–19 | 3D PCA projections and KDE angle distributions |
| 20–23 | Leaderboard, multi-seed evaluation with paired t-tests, bootstrap 95 % CIs |

Outputs (CSV tables and PNG/PDF/SVG figures) are written to the working directory, for example `eval_table1_own_samples.csv`, `eval_table2_common_samples.csv`, `test_metrics_with_95CI.csv`, `table_paired_ttest_vs_fcm_nsga2.csv`, `pareto_front.pdf`, `pca3d_all_algorithms.png`, `confusion_matrices_all.png`.

## Method details

- **FCM**: scikit-fuzzy, random initialization, tolerance 0.005, max 1000 iterations. Test memberships are computed from the training cluster centers; the hard label is the maximum-membership cluster.
- **NSGA-II** (pymoo): population 40, 50 generations, float random sampling, SBX crossover, polynomial mutation. Objectives: (1) MSE of retained-sample mean angles to the ideal template, (2) fraction of samples dropped.
- **Baselines**: K-Means, GMM and Hierarchical (Ward) use the best mean silhouette over K ∈ {2..6}; DBSCAN is tuned with NSGA-II (silhouette vs. noise ratio); FCM with a grid-searched threshold; and a fixed-tolerance rule (a sample passes only if every angle is within ±14° of its ideal).
- **Metrics**: total cumulative error, accuracy / precision / sensitivity / specificity / F1 / Cohen's κ (positive class = correct posture), coverage, paired t-tests across seeds, and bootstrap CIs over the 69 test images.

## Limitations

- Small test set (69 images) and two annotators; larger, more diverse validation is needed.
- 2D pose estimation depends on a true side-profile view; oblique cameras distort angles.
- Occlusion, loose clothing, and body shape can degrade MediaPipe landmark accuracy (notably shoulder and knee).
- NSGA-II is stochastic, and the selected threshold alternated between about 85 % and 95 % across seeds, so the number of images flagged for review varies (58.2 ± 4.4 of 69 retained).
- The claim that flagged samples are the truly ambiguous ones should be confirmed on per-sample data before relying on it clinically.
